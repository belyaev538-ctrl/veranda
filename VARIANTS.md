# Варианты лендинга VERANDARU

| Вариант | Git-ветка    | URL (локально / прод)     |
|---------|--------------|---------------------------|
| **1**   | `variant-1`  | `/`                       |
| **2**   | `variant-2`  | `/variant-2`              |

На одном деплое доступны оба URL: главная — вариант 1, `/variant-2` — вариант 2 (пока та же вёрстка, правки — в ветке `variant-2`).

В заявках в Telegram в источнике указано: **Вариант 1** или **Вариант 2**.

## Ветки

```bash
# Вариант 1 (текущая стабильная копия)
git checkout variant-1

# Вариант 2 (эксперименты)
git checkout variant-2
```

## Vercel

- Production с ветки `variant-1` → основной домен, `/`
- Preview с ветки `variant-2` → preview URL, `/variant-2`

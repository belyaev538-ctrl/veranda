# VERANDARU Landing

Premium landing page for VERANDARU — outdoor living for yachts & waterfront.

## Stack

- Next.js 14 (App Router)
- TypeScript (strict)
- Tailwind CSS
- Framer Motion

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Placeholders

Images use gray gradient placeholders labeled `PHOTO 01`–`PHOTO 18`. Replace via the `PlaceholderImage` component or swap to `next/image` when assets are ready.

Stub files are available in `/Заглушки` for reference.

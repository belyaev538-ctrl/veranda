# VERANDARU — Вариант 3 (`/v3`)

Техническое задание и контент-каркас для Cursor.  
**Сейчас:** `/v3` — копия `/v2` (тёмный Feadship + интро-компас). **Дальше:** пересборка по блокам ниже.

---

## Концепция

| Параметр | Решение |
|----------|---------|
| Сегмент | Премиум, яхты, UHNW |
| Тон | Минимум текста, максимум фото |
| Композиция | Full-bleed кадры на весь экран, текст внизу по центру |
| Скролл | Плавный, с parallax / crossfade между экранами (как сейчас на v2, усилить) |
| Кнопки | Контурные, обводка и текст **приглушённый бирюзово-голубой** (не яркий) |
| CTA финал | **«Назначить встречу»** — крупный экран, форма + соцсети |
| Интро | Компас (как v2), отдельный ключ `localStorage` для v3 |

**Цвет акцента (для v3):**  
`#6B9A9E` / `#7BA8B0` — muted teal, border + text on hover.

## Блок 08 — FAQ

| | |
|---|---|
| **Тип** | Кремовый или тёмный блок, accordion |
| **Заголовок** | Вопросы, которые задают до старта |

**Вопросы и ответы (черновик):**

1. **Сколько длится проект от брифа до монтажа?**  
   Обычно 8–16 недель в зависимости от сложности и сезона. Этапы: бриф → 3D → согласование → производство → монтаж.

2. **Работаете ли с верфью и капитаном?**  
   Да. Согласуем размеры, крепления, электрику, тенты с техническим отделом судна.

3. **Можно ли обновить только одну зону (refit)?**  
   Да. Flybridge, корма или кокпит — отдельными модулями.

4. **Какие гарантии на материалы?**  
   Зависит от линейки; прописываем в договоре. Сервисное сопровождение после сезона.

5. **География монтажа?**  
   Россия, Средиземноморье, ОАЭ — по согласованию с логистикой.

6. **Нужен ли выезд на яхту?**  
   Да, на этапе замера и приёмки — входит в проект или выезжает партнёр.
